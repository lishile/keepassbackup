# 项目协作约束

## 交流语言

- **始终使用中文**与用户进行交流，包括回答、解释、代码注释和所有文字输出。
- 代码本身（变量名、函数名、字符串等）保持原样，不强制翻译。

## Agent skills

### Issue tracker

Issues and specs are local markdown files under `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Triage uses five default status strings. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: root `GLOSSARY.md` and `docs/adr/`. See `docs/agents/domain.md`.
